# Portfolio

Yashaswini Kulshrestha's personal portfolio — Next.js 16 (App Router), Tailwind CSS v4, Framer Motion.

**Live:** https://portfolio-theta-six-21.vercel.app

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npx vercel --prod
```
